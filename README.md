# Cprof — الكتاب التفاعلي بالذكاء الاصطناعي

تطبيق Flutter/Android لعرض الكتب المدرسية بشكل تفاعلي. البداية: الرياضيات، المستوى الرابع ابتدائي.

## المرحلة الحالية
- واجهة عربية RTL.
- قارئ صفحات تجريبي.
- مناطق تفاعلية فوق الصفحة.
- لوحة شرح للعنصر المحدد.
- بنية جاهزة لإضافة AI لاحقًا دون ربطه بالكتاب بشكل عشوائي.

## الخطوة التالية
إضافة صفحات الكتاب المرخصة، ثم ربط كل منطقة بسياق: المستوى ← المادة ← الوحدة ← الدرس ← الصفحة ← العنصر.
